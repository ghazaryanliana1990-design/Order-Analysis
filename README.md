# Order Data Analysis & Visualization
## Overview
This project provides an end-to-end Exploratory Data Analysis (EDA) of sales order data using Python. The objective is to extract key business insights regarding customer purchasing patterns, regional distribution, and monthly order trends.
## Key Features & Workflow
** Data Preprocessing & Cleaning:** Loaded raw dataset using Pandas, handled missing values, and converted raw date strings into structured datetime objects for time-series evaluation.
** Exploratory Data Analysis (EDA):** Aggregated metrics across multiple dimensions, including top-performing regions, high-volume cities, and key individual customers using grouped statistics (groupby, value_counts).
** Data Visualization:** Built informative bar charts and timeline distribution plots using Matplotlib and Seaborn to highlight regional market leaders and seasonality in order volume.
## Tech Stack
**Language:** Python
**Libraries:** Pandas, Matplotlib, Seaborn
**Environment:** Jupyter Notebook
